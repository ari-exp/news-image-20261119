# World News — 19 November 2026

A one-day world news image summing up six stories first reported or happening on 19 November 2026.
Drawn programmatically with Pillow in a cute pastel style, with original shape-based icons and a chibi globe mascot.
Run `python3 draw.py` to regenerate `entry.png`; `main.py` copies that PNG to `MAKEFUN_OUTPUT_DIR`.
